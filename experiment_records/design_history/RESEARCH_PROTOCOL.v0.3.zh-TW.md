# LLM 決策與數學基準：研究計畫

版本：0.3，2026-11-10。取代 0.2 的「改善撤離」主問題；舊草案保存於 experiment_records/design_history。這次只有設計更新，沒有執行 API 或模擬。

## 研究定位

暫定題目：「群眾撤離志願者困境中，大型語言模型與賽局數學基準的決策差異及群體影響」。

數學模型是特定收益、均衡及行為修正假設下的理論基準，不保證撤離最快或社會福利最優，也不是人類真實行為標籤。必須分開評估「符合公式的程度」與「實際撤離效果」。偏離公式不一律稱為錯誤。

預期貢獻：(1) 同資訊下量測 LLM 與理論機率的差異；(2) 檢查成本、人數、阻塞與提示對差異的影響；(3) 分析這些決策差異如何形成群體結果。這些是研究目標，尚非已取得結論。仍須完成文獻定位，不宣稱首次應用或可預測真實災害行為。

## 主問題與公平性

| 問題 | 檢驗方式 |
|---|---|
| RQ1：LLM 是否理解同一個收益與行動問題？ | 獨立理解題，不以是否願意協助判定理解 |
| RQ2：LLM 決策與理論機率相差多少？ | 固定狀態下重複回答，估計協助率及差值 |
| RQ3：人數、成本、阻塞與措辭如何影響差異？ | 固定參數矩陣、反應曲線與穩健性檢查 |
| RQ4：決策差異造成什麼群體後果？ | 相同初始場景下比較撤離、負擔及運算成本 |

主實驗改用 Core：X、τ、cᵥ、aᵥ、ω。兩組共用觸發條件、Lv 空名單重判、候選人啟動、移動、衝突、推拉旋轉、工時與終止規則。沒有原模型決策需求時，不額外呼叫 LLM。

收益關係：自己選 C 得 1−cᵥ；自己選 D 且至少有人選 C 得 1；所有人選 D 得 1−aᵥ。限定 0<cᵥ<aᵥ<1，β=cᵥ/aᵥ。aᵥ 是無人協助的損失，不是搬運者的失敗傷害。ω 是機率模型係數，不直接當成人格評分。

原 Eq.(25) 包含出口暢通比例與不願意係數的行為修正，不是從收益表單獨推導的最優撤離解。X=1、τ=0、τ=1 分開核對邊界；τ=1 不啟動招募。τ=0 時基準 p=1 是理論假設，LLM 若理解後仍拒絕，記為相對該假設的差異。

LLM 取得收益與模型操作規則，但不取得公式算出的 p、別組答案、未來狀態或額外效益估計。行動標籤改為「參與／不參與協助」；不協助不代表一定能撤離。Prompt 已升為 v3 並實作這些語意；尚待真實理解檢查。

SharedContext 額外資訊、歷史記憶、中央分派及搬運效益預估暫不納入主實驗，只作可選延伸。不以修改提示直到合作為目標。

## 第一階段：共同狀態下的決策研究

1. 核對原文收益、Eq.(25)、觸發與邊界，列出規格對照。
2. 修正 Prompt，使用獨立開發題檢查成本與規則理解，不把合作當成通過標準。
3. 建立固定狀態題集，改變 X、β、τ；先固定 ω，再依預算擴充。範圍與重複次數在先導後鎖定。
4. 計算每個狀態的理論 p；LLM 用無共享歷史的新對話重複回答，記錄模型、提示、temperature、失敗與原始回答。
5. 分析每狀態協助率差、整體絕對差、參數反應曲線及區間。不能用單一二元答案對機率基準算一般分類正確率。
6. 狀態是比較區塊；相似狀態的數千次呼叫不能當成數千個獨立場景。報告原始計數、分母與失敗率。
7. 固定主要模型與中性提示；第二模型為建議的穩健性檢查，依預算決定，不事後挑最好者。理由文字不是因果證據。

本版維持直接二元決策。要求模型報機率屬另一項任務，不能不加區分地混入。

## 第二階段：閉迴路撤離研究

主比較為 Core LLM 與 OriginalGameTheory。NoVolunteers 是物理負對照；Heuristic 與 RandomMatched 為解釋性對照，可分層增加，避免一次過多組別。

場景分為單出口完全阻塞、部分阻塞、另有可用出口。共用初始布局、行人位置、種子及上限 H；原參考設定先固定，再研究密度與搬運工時。不能從單一完全阻塞案例推論所有情況都需要協助。

主要指標：H 內全員撤離率與 min(T100,H)。物理未完成者取 H，但不稱真正 T100。API、解析與安全上限失敗為 invalid，單獨揭露，不當成物理逾時。不能將 LLM 第 2 步因額度停止與賽局第 13 步完成相比，宣稱前者更快。

次要指標：合作率、搬運者啟動、障礙位移、總工時、全體個人負擔、API attempts、tokens 與等待時間。現有工時不包含成為搬運者前的接近路程。

RandomMatched 需使用獨立校準資料並凍結機率；測試期實際合作率未必相同，必須揭露差距，不能宣稱完全排除合作頻率因素。決策 RNG 已分離，但不同軌跡仍可能消耗不同物理亂數。

## 資料、統計與鎖定

開發／理解題、先導／校準、最終測試分開，狀態與種子的用途不重疊。先導決定成本、變異、合理 H、樣本數及預算，不混入最終測試。預先固定主比較、精度需求、失敗處理與多重比較標示。

決策研究需新增狀態層級分析；現有種子區塊撤離分析不能直接取代。撤離研究以整次執行為單位，不將每步或每人當獨立樣本。

所有新模擬已預設自動追加英文紀錄、索引與分類資料。新增固定狀態研究也必須接入同一紀錄系統。舊測試保留為開發診斷，不回填為新版正式資料。
