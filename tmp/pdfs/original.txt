Introduction 
Crowd evacuation simulation is an important research topic for improving public 
safety during emergencies such as fires and earthquak es. Existing evacuation 
models commonly employ Cellular Automata and Floor Field methods to 
simulate pedestrian movement and evaluate evacuation efficiency. 
In this work, we investigate whether a Large Language Model (LLM) can improve 
volunteer coordinatio n in crowd evacuation. We replace the original game - 
theoretic volunteer decision module with an LLM - based reasoning framework 
while preserving the remaining simulation components for a fair comparison. 
Experimental results demonstrate improved evacuation e fficiency together with 
interpretable volunteer decisions. 
The main contributions of this work are summarized as follows: 
1.   We replace the original game - theoretic volunteer decision model with an 
LLM - based reasoning framework. 
2.   We preserve the original evacua tion framework to enable a fair comparison. 
3.   We improve evacuation performance while providing interpretable volunteer 
decisions. 
Background 
II. Background 
The proposed work is based on the crowd evacuation framework introduced by 
Lin and Wong [1]. The simulation environment consists of multiple exits, some of 
--- PAGE 2 ---
which may be blocked by obstacles. Pedestrians move toward available exits 
using Cellular Automata (CA) and Floor Field guidance. Unlike conventional 
evacuation models, the framework allows pedestrians to voluntarily remove 
obstacles, enabling blocked exit s to become available again and improving 
evacuation efficiency. 
To determine volunteer behavior, the original model adopts the Volunteer's 
Dilemma, a game - theoretic approach that estimates the probability of an agent 
becoming a volunteer based on predefined mathematical equations. Potential 
volunteers are first identifi ed, after which a volunteer is assigned to remove each 
obstacle. Although this approach effectively models volunteer behavior, its 
decision process mainly relies on predefined rules and limited local information. 
This limitation motivates the use of LLM - b ased reasoning for volunteer 
coordination, which is introduced in the following section.

Proposed LLM Volunteer Coordination 
Instead of using a predefined mathematical model, the proposed approach 
employs an LLM to determine volunteer assignments. The LLM reasons over the 
current evacuation context and generates volunteer coordination decisions.

The Simulation Core manages the overall simulation loop. The Environment 
Layer maintains map information and floor - field guidance. The Agent Layer 
controls pedestrian movement, while the Decision Layer performs volunteer 
coordination. Finally, the Data Exp ort module records simulation statistics for 
evaluation. 
Only the volunteer decision module is modified in this work. 
Compared with the original framework, all simulation components remain 
unchanged except for the volunteer decision module. This design minimizes 
implementation bias and enables a fair comparison between the original and 
proposed approaches. 
Explainable Volunteer Reasoning 
Unlike the original mathematical model, the proposed approach not only 
generates volunteer assignments but also provides natural - language 
explanations describing the reasoning behind each decision. This additional 
information improves the interpretability   of the volunteer coordination process 
Fig 5   ( Example of LLM - generated volunteer reasoning ) 
The generated reasoning allows users to understand why a particular volunteer is 
selected. Instead of only producing a final assignment, the LLM explicitly 
describes the contextual factors considered during decision making, such as 
obstacle impact, volunte er distance, and surrounding pedestrian density. 
Although the reasoning itself does not directly affect simulation performance, it 
provides additional transparency that is unavailable in the original model. Such 
explainable outputs facilitate result analysis and may support future human - AI 
collaborative   evacuation planning.

Experiments were conducted in a grid - based evacuation environment with four 
exits and randomly generated obstacles. Four crowd densities (60, 90, 120, and 
150 agents) were evaluated. Each scenario was repeated 30 times to reduce 
randomness, and volunteer s election was performed every six simulation steps. 
Evaluation Metric 
Performance was evaluated using the T90 evacuation time, which represents the 
number of simulation steps required for 90% of pedestrians to successfully 
evacuate. A lower T90 value indicates better evacuation efficiency.

Discussion 
Advantages 
Global Coordination 
Unlike the original model, which assigns volunteers independently for each 
obstacle, the proposed framework considers all obstacles and candidate 
volunteers simultaneously. This global coordination helps reduce redundant 
assignments and improves overall ev acuation efficiency. 
Context Awareness 
The LLM utilizes richer contextual information, including obstacle impact, 
volunteer distance, and nearby pedestrian density. This enables more 
adaptive decisions under different evacuation scenarios. 
Explainability 
In addition to volunteer assignments, the proposed framework provides 
natural - language reasoning that explains the decision process. Such 
explanations improve transparency and facilitate result analysis. 
Limitations 
API Cost 
Inference Time 
Prompt Dependency 
The quality of volunteer assignments depends on the prompt design and the 
capability of the selected LLM.

Conclusion 
This work presented an LLM - based volunteer coordination framework for crowd 
evacuation simulation. By replacing the original game - theoretic volunteer 
decision module while preserving the remaining simulation framework, a fair 
comparison between the origina l and proposed approaches was achieved. 
Experimental results demonstrated that the proposed method consistently 
reduced the T90 evacuation time under different crowd densities. Furthermore, 
the LLM provided interpretable decision reasoning, improving the t ransparency 
of volunteer coordination. These results suggest that LLM - based reasoning is a 
promising approach for enhancing volunteer decision - making in crowd 
evacuation simulations. 
Future work 
Several directions can be explored in future research. First, more complex 
evacuation scenarios, such as dynamic obstacles and changing environments, 
could be considered to evaluate the robustness of the proposed framework. 
Second, different LLMs or locall y deployed language models may be investigated 
to reduce inference cost and improve response time. Finally, integrating real - 
world evacuation data and human behavioral studies could further validate the 
effectiveness and practicality of the proposed volunt eer coordination 
framework.
