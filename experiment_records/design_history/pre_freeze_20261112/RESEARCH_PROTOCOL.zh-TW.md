# 個人 LLM agent 與原賽局模型的情境比較

版本：0.5.2（個人 P1 修訂，未鎖定），2026-11-11。這是目前主線，取代先前以全域分派為主要比較的 v0.4／S5。舊 source、資料與不可變 lock 已完整保存，見 [封存說明](experiment_records/design_history/global_coordination_s5_v1.md)。

## 核心問題與可主張的貢獻

在原論文相同觸發、資訊條件、啟動與搬運規則下，個人 LLM 的協助選擇如何隨成本、合資格玩家數與出口阻塞而改變？相對原賽局模型的差異在何種情境下出現，如何累積為志工形成與撤離結果？

研究不以 LLM 必須勝過原模型為目標。不將偏離公式叫作錯誤、不理性或更像人；原模型提供特定假設下的參與機率，沒有真人資料就不宣稱行為真實性。預期貢獻是受控且可重現的條件反應比較、差異的替代解釋檢查，以及個人決策到群體後果的證據鏈。能否形成新穎結論仍需相關文獻定位與實驗支持。

## 研究邊界

- 兩者都是行人代理，只替換個人的參與決策。主模式固定 PaperRelocation + PaperReference + PolicyWillingness。
- 主資訊為 Core 的五個模型輸入；不額外給 LLM 其他人的當次選擇、路線、全域任務表或未來效益。
- 不引入全域分派、最佳化預約、人格、記憶、反思或溝通作主要自變項。保留程式不代表納入研究。
- 不改動原論文協助觸發；潛在志工不是已啟動搬運者，相鄰啟動／合法放置／物理規則共用。

## 分組

| 條件 | 決策 | 後續流程 |
|---|---|---|
| 原模型 | OriginalGameTheory 的參與機率及隨機選擇 | 原模式相鄰啟動與搬運 |
| 個人 LLM | 每次一名行人的 participate / decline_assistance | 同上 |
| RandomMatched（輔助） | 依獨立校準資料匹配預先定義條件的平均參與率 | 同上 |
| NoVolunteers（負對照） | 不參與協助 | 同一物理引擎 |

RandomMatched 是排除「只是平均參與率不同」的簡單控制，不預設它能匹配每個狀態。不可用正式測試決策或結果校準。若只需描述參與分布，無記憶二元 LLM 也可能被簡單機率代理近似；不能把差異直接當成高階推理或社會智慧的證據。

## 兩層實驗

第一層：固定個人狀態，控制 cv、合資格玩家總數 X（含本人）、tau（未阻塞比例），固定 av、omega 與其他設定。具體層級與重複數待規格複核／先導後鎖定。記錄原模型機率與 LLM 參與分布、條件反應差異及區間；不把一次行動當成個人機率。X=0、tau=1 等不觸發狀態是程序負對照，不強行送出原流程不會發出的問題。P1 已核對 X=1 原文分支：該分支只屬於原模型策略；LLM 與 RandomMatched 仍自主選擇，X=1 以 ReferenceBoundary 標記並分層分析；多玩家 tau=0 仍保留選擇，不強迫 C。

第二層：相同布局與初始種子下替換個人決策機制。觀察 H 內全員撤離、受限 T100、無志工事件、搬運啟動與全體協助負擔。初始行人總數不是動態的 X，布局／障礙數也不是 tau；分析需使用實際決策狀態。不同策略產生不同軌跡後，不把閉迴路參與率差異直接當成同狀態下的反應差異。

措辭穩健性是輔助檢查。現有 Standard／Alternate 同時改變開頭表達與呈現先後，尚不能作純選項順序的單因子結論；若要拆分，需另定義與版本化。SharedContext 暫不列主比較。

## 分析與失敗處理

- 主要關注條件反應差異；精確主要對照、交互作用、樣本數及多重比較處理尚未預註冊。
- 理解問題、協助選擇、API／格式失敗分開。理解通過不代表必須選擇協助。
- 固定狀態重複與閉迴路同人／同種子觀測具有依賴性；不把每步決策當獨立樣本。
- API invalid 不填成拒絕或物理 timeout；保存所有失敗、不只留下成功樣本。有效未完成的受限時間用共同 H，無效執行另報。
- 負擔包含零貢獻者；晚撤離不直接解釋為協助造成的因果延遲。解釋文字僅作探索性材料，不當成模型內部推理的可靠觀測。
- 等平均參與率控制只支持排除該層級的替代解釋，不自動識別差異的唯一原因。

## 現有成果與不能沿用的結論

物理／賽局／個人介面、v5 提示、Core、決策 RNG、trace、回放、自動英文紀錄及校準／分析基礎可沿用。既有 8/8 理解結果與 smoke 是開發證據，沒有新的正式情境比較結果。v3 的理解結果不能改稱 v5 通過。

原 S5 的 480 快照與 934 排程屬全域分派設計，不是新主線正式計畫。160 個數學意願情境可審查為開發素材，不能直接承接舊 split、來源假設或預算。舊個人 study_plan.template.json 亦固定了不再適用的 SharedContext 主對照及額外控制組；需更新工具、完成新校準後才能凍結。
